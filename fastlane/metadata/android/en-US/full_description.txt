F-Droid build: updates come from F-Droid only. Switching from the GitHub APK needs an uninstall + reinstall (different signature) — back up first via Settings → Data export, then import here.

RadioScout is a free worldwide radio player. Discover top stations by votes, search the full directory, filter by genre, country, language or bitrate, save favourites, track recent plays and listening stats — all on-device, no accounts, no sync, no tracking.

Features:
- 80,000+ stations from the community radio-browser directory (playable https streams only)
- Saved favourites with reorder, recent plays, listening trends and streaks
- Persistent player with crossfade, volume, per-station leveling, sleep timer
- Station sheets with art, tags, votes and shareable links
- One-file backup export/import for moving between devices
- Light/dark theme, quick-find palette, PWA install on desktop
